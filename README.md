# ⏱️ Time Tracking System – Productivity Manager

## 📌 About the Project
Time Tracking System is a productivity management application developed using C and Web Technologies. It helps users manage daily tasks, track time spent on activities, and monitor their productivity.

The project combines a C-based task management system with a web-based dashboard for a better user experience.

## ✨ Features
- Add and manage tasks
- Categorize tasks
- Start and stop task timers
- Track time spent on individual tasks
- Mark tasks as completed
- Store task information using file handling
- View productivity summaries
- Interactive web dashboard
- Productivity charts and reports

## 🛠️ Technologies Used
- C Programming
- HTML
- CSS
- JavaScript
- Chart.js
- File Handling
- Local Storage

## 📂 Project Structure
- C-Project – C source code and task storage
- Web-Dashboard – HTML, CSS and JavaScript files
- README.md – Project documentation

## 🚀 How to Run

### C Project
1. Install GCC compiler.
2. Open the project folder in VS Code.
3. Compile the C program:

```bash
gcc main.c -o TimeTrackingSystem
```

4. Run the program:

```bash
./TimeTrackingSystem
```

### Web Dashboard
1. Open the Web-Dashboard folder.
2. Open `index.html` in your browser.

## 🎯 Objective
The main objective of this project is to improve time management, task organization, and productivity through simple time-tracking tools.
